## Roles and launch

Clone the fixture for the coordinator, apart from this packet, and keep worktrees beside it:

```
mkdir -p $HOME/r2 && git clone https://github.com/wilsonkichoi/wkc-yolo-fixture-r2-cloud-20261104.git $HOME/r2/coord
```

Each coordinator turn's prompt is its first line(s) below, then a blank line, then the common
prompt. A resumed turn is the person's reply alone. Launch from `$HOME/r2/coord` in its own
process group, so a checkpoint stop also ends its native agents:

```
setsid claude -p --model opus --effort high --dangerously-skip-permissions --settings '{"sandbox":{"enabled":false}}' --output-format stream-json --verbose < <prompt file> > <raw>/<label>.jsonl 2> <raw>/<label>.stderr
```

Add `--resume <session id>` for a later turn of the same case. Take the session id from the first
turn's `system` init line. `<raw>` is the evidence clone's `raw/` (Evidence and pushes).

Common prompt:

```
You are the coordinator under test. Use the wkc-yolo skill installed in this checkout, .claude/skills/wkc-yolo/SKILL.md, and its installed dependencies, and follow it. This is a throwaway GitHub fixture; its AGENTS.md records the person's authorization and the GitHub transport for this run, and both bind you and every worker. Access only this checkout and worktrees you create under $HOME/r2/wt. Do not read any other directory, the skills source repository, or validation notes. The person authorizes Claude workers with the fixture's configured pair, native or headless as the installed adapters allow. At most 3 workers may run at once. Workers never start subagents, another harness, or AI test sessions. Give workers the same repository boundary, transport rule, and stop rules. Stop immediately on the first real quota, rate-limit, or authentication error. Do not retry. Do not publish or tag releases. Merge only into the run branch. Every step is a fresh worker session. Do not resume a worker unless the person explicitly authorizes recovery of an interrupted step.
```

The driver acts as the person. Answer a question only after the turn has ended and you have read
the whole question or draft. Pick the option that matches the reply given for that turn below,
by its number. Never tell the coordinator what the test expects, and never send a turn the case
does not call for. R's driver once sent an unneeded reply; it still counted as a session.
